## 项目名称

麦麦健康搭子（McDonald's Health Buddy）

## 项目地址

https://github.com/Qiqian07/mcd-health-buddy

## 项目简介

麦麦健康搭子是一个基于麦当劳中国官方 MCP 能力开发的 Skill：帮用户按热量/蛋白质等健康目标，用官方真实营养数据智能搭配 2~3 套套餐方案，自动校验门店可售性，再叠加卡包券、门店券和积分商城兑换逐级比价，输出"健康搭配卡片 + 省钱报告"，用户确认后一句话完成下单。

核心亮点：

- 🥗 差异化角度：不卷"怎么买"，解决"怎么吃得又健康又划算"——基于 `list-nutrition-foods` 官方营养数据做科学搭配（热量目标 + 高蛋白 + 控钠）
- 💰 优惠联动：整合 `query-my-coupons` / `query-store-coupons` / `calculate-price` 输出「原价 → 券后价 → 积分组合价」省钱报告
- 🏆 积分最优解：自动比较"直接买 vs 积分兑换"（`mall-points-products`），给出更划算的组合
- 📅 活动联动：结合 `campaign-calendar` 提醒用户哪天吃更划算
- 🛵 全场景覆盖：到店/外送/积分兑换，下单前强制展示订单摘要并经用户确认

技术形态：纯 Skill（提示词工程 + MCP 工具编排），零自定义代码，全部数据与交易能力来自麦当劳官方 MCP Server（https://mcp.mcd.cn）。

开发工具：腾讯 WorkBuddy（完整开发对话记录见仓库 `开发对话记录.md`）。
